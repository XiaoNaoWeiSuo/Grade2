# Grade2 — 长江大学课程表

> 专为**长江大学**设计的课程表应用。零服务器、纯本地运行，数据绝不上传任何第三方。

## 一句话

通过爬虫内核模拟登录长江大学教务/CAS/aTrust 系统，抓取课表、成绩、考试、培养计划、选课等数据，本地持久化支持离线查看。**所有操作在设备上完成，没有后端服务器。**

---

## 核心设计理念

### 零服务器 · 纯本地架构

本项目**没有服务器、没有数据库、没有云服务**。用户登录凭据和所有数据处理完全在设备本地执行：

- 登录、抓取、解析全部在手机端完成
- 会话状态以 Cookie 形式持久化在本地文件
- 密码通过系统安全存储（iOS Keychain / Android Keystore）保护，**永不落盘为明文**
- 业务数据通过 JSON 文件原子写入本地存储
- **没有任何网络请求会发送到除长江大学教务系统之外的任何服务器**

### 隐私保护

- 密码仅在 CAS 登录 POST 时存在于内存中，登录后即丢弃
- 密码存储使用 `flutter_secure_storage`（系统级 Keychain/Keystore），不出现在仓库、日志或缓存文件中
- 会话 Cookie 与业务数据严格分离存储
- 会话令牌（CASTGC）有效期 14 天内走 SSO 免密，不重复消耗密码
- 防封号硬约束：每会话最多 1 次密码 POST，凭据异常绝不自动重试

### 架构先进性

采用 **严格 MVVM + Riverpod 2.6** 分层架构，实现关注点彻底分离：

```text
views → viewmodels → core（crawler / storage）
                         ↑
                         零依赖（仅 Dart 标准库）
```

| 层 | 职责 | 依赖约束 |
|---|---|---|
| **core** | 爬虫内核 + 本地缓存 | 零 Flutter、零第三方，纯 Dart 标准库 |
| **viewmodels** | 状态管理 + 业务编排 | 不 import Flutter，不 new 内核对象 |
| **views** | Cupertino UI 表现 | 依赖 viewmodels，禁止反向引用 |

**内核零第三方依赖**：爬虫内核仅使用 `dart:io`、`dart:convert`、`dart:math`、`dart:typed_data`、`dart:async`，可被单测/命令行脚本复用。业务数据全部为原生 `Map<String, Object?>` / `List`，与 Python 原版爬虫输出 1:1 对应，已通过 golden 逐字段比对验证。

### 性能优化

- **缓存优先 + 离线可用**：只读数据 Cache-first，命中即渲染，离线仍可查看；`refresh()` 才触发在线请求
- **原子写入**：本地缓存采用 tmp + rename 原子写，避免写入中断导致数据损坏
- **会话缓存复用**：`ensureApi()` 检测缓存新鲜度，若 Cookie 仍存活则零网络请求直接返回
- **懒加载渲染**：长列表使用 `SliverList.builder` 懒加载，避免一次性全量构建
- **自动会话重建**：会话失效时 `withApi` 静默重建链路，业务层无感知
- **SAX 式 HTML 解析**：自建纯 Dart SAX 解析器，避免 DOM 树构建的内存开销
- **会话状态跨进程互通**：Dart 端可载入 Python 会话并复用 CASTGC

## 功能概览

| 模块 | 能力 |
|---|---|
| 课表 | 常驻首页，Table 网格 + 周翻页 + 学期切换 |
| 选课 | 轮次列表 → 课程 + 余量 → 选/退（跨接口编排） |
| 考试 | 批次/安排 + 四六级 + 中期考核 |
| 成绩 | 表格 + 全局学期联动 |
| 培养计划 | 完成度 / 我的计划 / 培养方案 / 转专业 |
| 学籍 | 分段 KV + 头像 |
| 消息 | 系统消息列表 |
| 教学评价 | 评价任务列表 |

**国际化**：简体中文 / 繁體中文 / English / 日本語 / اردو（5 种语言）
**主题**：跟随系统 / 亮色 / 暗色 / 护眼（4 种模式）

## 技术栈

| 层 | 选型 |
|---|---|
| 语言/平台 | Dart + Flutter（`sdk: >=3.11.0 <4.0.0`） |
| UI 风格 | 纯 Cupertino（iOS 原生风格） |
| 状态管理 | Riverpod 2.6 |
| 安全存储 | flutter_secure_storage（Keychain / Keystore） |
| 内核实现 | 纯 Dart 标准库（零第三方） |
| 缓存 | 自建 LocalCache（命名空间 JSON + 原子写） |
